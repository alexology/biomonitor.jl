Biomonitor.Biomonitor — Module
Biomonitor

Native Julia port of the R package biomonitoR (version 0.9.5): import and validation of community data against taxonomic reference databases, aggregation at taxonomic levels, diversity indices, biotic indices (BMWP, ASPT, WHPT, LIFE, PSI, E-PSI, DEHLI, IBMR, ...), trait assignment and functional diversity (FRic, FDis, FEve, Rao's Q, functional redundancy).

All data are stored in Julia types (CommunityTable, ReferenceDB, BiomonitorData, AggregatedData, TraitTable, AssignedTraits, DistMatrix, LabeledVector, LabeledMatrix); no R runtime is needed.

Biomonitor.CommunityTable — Type
CommunityTable(taxa, samples, abundance)

Taxa × samples table of abundances (or presence-absence values). This is the input of as_biomonitor (the R data.frame with a Taxa column) and also the per-level tables stored in an AggregatedData. Missing values are stored as NaN.

Construct it from vectors and a matrix, or from a NamedTuple/Dict of columns where the Taxa column holds the names and every other column is a sample, e.g. CommunityTable((Taxa = ["Baetis"], S1 = [3], S2 = [0])).

source
Biomonitor.ReferenceDB — Type
ReferenceDB(ranks, taxa)

Taxonomic reference database: ranks is an n × 10 matrix of names for the RANKS (empty string when a rank is not defined) and taxa the n taxon names that can appear in the data. Built-in databases are returned by reference_db; custom ones can be read with read_reference or built with ref_from_tree.

source
Biomonitor.BiomonitorData — Type
BiomonitorData

Result of as_biomonitor (R class asb): the user data merged with the reference database. Fields:

  • ranks: n × 10 matrix with the taxonomic tree of each taxon;
  • taxa: taxon names; samples: sample names;
  • abundance: n × samples matrix;
  • group: :mi, :mf, :fi, :di or :custom;
  • presence_absence: true when imported with FUN = bin;
  • corrected_names: names changed through to_change (wrong => correct);
  • suggested_names: names not found in the reference with spelling suggestions (excluded => suggestions).
source
Biomonitor.AggregatedData — Type
AggregatedData

Result of aggregate_taxa (R class biomonitoR): the imported data plus one CommunityTable per taxonomic level. Index it with a level: x[:Family], x["Genus"]. Taxa without a name at a level are pooled in the row "unassigned". x.data is the underlying BiomonitorData (the R Tree element).

source
Biomonitor.TraitTable — Type
TraitTable(taxa, traits, values)

Taxa × traits table (fuzzy-coded affinities or continuous values). NaN marks missing values. Built-in tables: traits_tachet, traits_mf, diatom_traits. Read your own with read_traits.

source
Biomonitor.AssignedTraits — Type
AssignedTraits

Result of assign_traits: one row for each pair (taxon in the data, taxon of the trait database whose traits were assigned to it). Fields:

  • taxa: taxon of the user data;
  • taxa_level: its taxonomic level;
  • trait_taxa: taxon of the trait database providing the traits;
  • trait_level: its taxonomic level;
  • distance: taxonomic distance (positive when the trait taxon is finer, e.g. traits of a species assigned to a genus);
  • traits, values: trait names and values.

In the R package these columns are called Taxa, Taxa_db, Traits_taxlev, Traits_real and Taxonomic_distance.

Import and data management

Biomonitor.as_biomonitor — Function
as_biomonitor(x::CommunityTable; group = :mi, dfref = nothing,
              to_change = :default, FUN = sum, correct_names = false) -> BiomonitorData

Merge the community table x with a taxonomic reference database.

  • group: :mi macroinvertebrates, :mf macrophytes, :fi fish, :di diatoms (ignored when dfref is given).
  • dfref: a custom ReferenceDB.
  • to_change: names to replace before the check, as Pairs "Taxon" => "Correct_Taxon" (a Dict or a vector of pairs). With :default, Hydracarina, Hydracnidia and Acariformes become Trombidiformes. nothing disables the replacement.
  • FUN: sum for abundances, bin for presence-absence data.
  • correct_names: false removes the taxa not found in the reference (spelling suggestions are stored, see excluded_taxa); a Dict wrong => correct renames them; true asks interactively on the terminal for each unknown name.

Taxon names are capitalised (first letter upper case), rows with the same name are aggregated with FUN and missing values are set to 0.

Biomonitor.dness — Function
dness(x::AggregatedData; complete = false, tax_lev = :Genus,
      method = "delta", taxa_tree = false)

Taxonomic diversity and distinctness indices:

  • "delta": taxonomic diversity Δ;
  • "delta.st": taxonomic distinctness Δ*;
  • "delta.bin": Δ computed on presence-absence data (Δ+).

Path lengths between taxa are counted on the levels Phylum, Class, Order, Family, Genus and Species down to tax_lev; levels with missing names and levels that do not discriminate are dropped, and distances are scaled so that the largest is 100 (as vegan's taxa2dist(varstep = FALSE)). With complete = false an error is raised if some taxa are unassigned at tax_lev; with complete = true they are excluded. taxa_tree = true also returns the taxonomic table used.

Biomonitor.bmwp — Function
bmwp(x::AggregatedData; method = "ita", agg = false, exceptions = nothing,
     traceB = false)

Biological Monitoring Working Party score: sum of the scores of the scored families present in each sample.

  • method: "ita" (Buffagni et al. 2014), "spa" (Alba-Tercedor et al. 2002), "a" (Armitage et al. 1983), "uk" (Davy-Bowker et al. 2008), or a custom Dict taxon => score (see show_scores).

  • exceptions: taxa whose abundance is removed from their scored parents and whose scored children are excluded.
  • traceB = true returns a NamedTuple with results, the scored taxa (taxa_df), the merged composite taxa, the exceptions and the parent-child pairs whose abundances were corrected.

Traits

Biomonitor.assign_traits — Function
assign_traits(x::AggregatedData; trait_db = nothing, group = :mi, tax_lev = :Taxa,
              dfref = nothing, filter_by_distance = nothing) -> AssignedTraits

Assign traits to the taxa of x, also borrowing them across taxonomic levels (from Subspecies to Family). For instance a genus present in the data receives the traits of its species in the trait database, and a species missing from the trait database receives the traits of its genus. When traits exist at the matched level, traits of other taxa at that level are discarded (e.g. Anabolia lombarda gets the traits of Anabolia, not those of Anabolia nervosa).

  • trait_db: a TraitTable; the default is traits_tachet (macroinvertebrates).
  • dfref: reference database to place the trait taxa in the taxonomy (default: the built-in one for group).
  • tax_lev: work at a coarser level (:Family at most).
  • filter_by_distance: :pos (traits from equal or finer taxa), :neg (equal or coarser) or an integer (maximum absolute distance).

Use manage_traits to select among multiple assignments and average_traits or sample_traits to obtain one row per taxon.

source
Biomonitor.manage_traits — Function
manage_traits(x::AssignedTraits; method = "nearest+-", traceB = false) -> AssignedTraits

Select, for each taxon, the traits assigned from the taxonomically nearest taxa:

  • "nearest": smallest distance, irrespective of the direction;
  • "nearest+": nearest among taxa of equal or finer level;
  • "nearest-": nearest among taxa of equal or coarser level;
  • "nearest+-": nearest giving priority to equal or finer taxa;
  • "nearest-+": nearest giving priority to equal or coarser taxa.

With traceB = true also returns the taxa excluded by the selection.

Functional diversity and distances

Biomonitor.f_rich — Function
f_rich(x::AggregatedData; trait_db, tax_lev = :Taxa, type = nothing,
       col_blocks = nothing, nbdim = 2, distance = "gower", zerodist_rm = false,
       correction = "none", traceB = false, set_param = nothing) -> LabeledVector

Functional richness (Villéger et al. 2008): volume of the convex hull of the taxa of each sample in a PCoA functional space with nbdim axes, relative to the volume of all taxa. Samples with fewer than nbdim + 1 taxa get 0.

  • trait_db: a TraitTable (type = "F" fuzzy with col_blocks, or "C" continuous) or a DistMatrix.
  • distance: "gower" (fuzzy traits) or "euclidean" (scaled traits).
  • nbdim: number of axes, or :auto to choose it with qfs (first space with mean squared deviation < 0.01).
  • zerodist_rm: merge taxa with identical traits.
  • correction: "none", "cailliez", "lingoes", "sqrt", "quasi" to make the distance Euclidean.
  • set_param: NamedTuple with max_nbdim (15), tol (1e-7) and cor_zero (true).

f_disp(x::AggregatedData; trait_db, ...) -> LabeledVector

Functional dispersion (Laliberté & Legendre 2010): abundance-weighted mean distance of the taxa to the community centroid in the PCoA space. Same arguments as f_rich; with nbdim axes treated as positive and the others as negative (as in the R implementation).

Biomonitor.select_pcoa_axes — Function
select_pcoa_axes(d; method = "legendre", tresh = nothing, nbdim = 15,
                 nrepet = 999, rng = Random.default_rng()) -> Vector{NamedTuple}

Choose the number of PCoA axes for a trait distance. For a non-Euclidean distance one row is returned for each transformation (none, cailliez, lingoes, sqrt, quasi).

  • "legendre": first axis where the cumulative eigenvalues exceed tresh (default 0.7; Legendre & Legendre 2012, with the correction for negative eigenvalues);
  • "cor": first axis where the Mantel correlation between the original and the PCoA distances exceeds tresh (0.7); p-values come from nrepet permutations, so they vary between runs;
  • "maire": first space with mean squared deviation below tresh (0.01; Maire et al. 2015).

Biomonitor.gower_fuzzy — Function
gower_fuzzy(V::AbstractMatrix, col_blocks; tol = 1e-8) -> Matrix
gower_fuzzy(t::TraitTable, col_blocks) -> DistMatrix

Distance between taxa described by fuzzy-coded traits, as computed by ade4::dist.ktab(ktab.list.df(list(prep.fuzzy(...))), type = "F"): for each trait the overlap distance $1 - \sum p_i q_i / \sqrt{\sum p_i^2 \sum q_i^2}$ (Manly), averaged over the traits and square-rooted. Traits with missing values are skipped pair by pair. The input must already be prepared with prep_fuzzy (rows of each block sum to 1 or are NaN). Block sizes must be positive and cover every column exactly once.

Biomonitor.indicator_taxa — Function
indicator_taxa(x::AggregatedData; clusters = nothing, tax_lev = :Taxa, nmax = 10,
               thresh = 25, method = "ward.D2", parent = :Order) -> NamedTuple

Indicator taxa analysis behind R plot_indicator_taxa.
